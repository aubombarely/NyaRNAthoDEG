# NyaRNAthoDEG — Test Data

## Overview

The test enters the pipeline at **Module 7** (DESeq2 + topGO), bypassing tools
that require large external resources (FASTQ files, STAR genome index, BAM files).
All test data is generated synthetically by `make_test_data.py`.

---

## Experiment design

| Factor | Levels |
|---|---|
| DevelopmentalStage | Stage1, Stage2 |
| Temperature | L (low), H (high) |
| Replicates | 2 per condition |
| **Total samples** | **8** |

### Baked-in signal (detectable by DESeq2)

| Genes | Effect |
|---|---|
| SMELv4.1_00001 – SMELv4.1_00100 | ~4× up in Temperature **H** |
| SMELv4.1_00101 – SMELv4.1_00200 | ~4× down in Temperature **H** |
| SMELv4.1_00201 – SMELv4.1_00300 | ~3× up in **Stage2** |
| SMELv4.1_00301 – SMELv4.1_00400 | ~3× down in **Stage2** |
| SMELv4.1_00401 – SMELv4.1_00500 | no differential expression |

## Files generated by `make_test_data.py`

| File / Directory | Description |
|---|---|
| `test_samples.tsv` | Sample sheet (StartingModule=7 for all samples) |
| `htseq_counts/` | 8 synthetic HTSeq count files |
| `test_ahrd.txt` | AHRD-format annotation (6 columns, 500 genes) |
| `test_fantasia.txt` | FANTASIA GO annotation in topGO format |
| `test_annotation.gtf` | Minimal dummy GTF *(CLI placeholder only)* |
| `test_genome_dir/` | Empty directory *(CLI placeholder only)* |

---

## Quicktest

```bash
conda activate NyaRNAthoDEG

# Step 1 — generate test data (run once)
python3 test/make_test_data.py

# Step 2 — run pipeline (Module 7 only)
python3 scripts/NyaRNAthoDEG.py \
    --sample_sheet   test/test_samples.tsv \
    --genome_dir     test/test_genome_dir \
    --gtf            test/test_annotation.gtf \
    --annot_ahrd     test/test_ahrd.txt \
    --annot_fantasia test/test_fantasia.txt \
    --output         test/test_run \
    --deseq_design   "~ DevelopmentalStage + Temperature" \
    --deseq_stratify DevelopmentalStage \
    --skip_module1 --skip_module2 --skip_module3 \
    --skip_module4 --skip_module5 --skip_module6
```

## Expected outputs

After a successful run, `test/test_run/results/mod07_deseq2/` should contain:

| File | Description |
|---|---|
| `test_run_DEG_annotated.csv` | Merged DEG table with normalized counts + annotations |
| `test_run_PCA.pdf/.png` | PCA plot (Stage × Temperature coloured) |
| `test_run_SampleDist_heatmap.pdf` | Sample distance heatmap |
| `test_run_UpSet.pdf` | UpSet plot (DEG overlap across Stage1 / Stage2) |
| `test_run_GOSEA_Homology_BP_Stage1_table.txt` | topGO table — Homology, Stage1 |
| `test_run_GOSEA_Homology_BP_Stage2_table.txt` | topGO table — Homology, Stage2 |
| `test_run_GOSEA_FANTASIA_BP_Stage1_table.txt` | topGO table — FANTASIA, Stage1 |
| `test_run_GOSEA_FANTASIA_BP_Stage2_table.txt` | topGO table — FANTASIA, Stage2 |
| `test_run_HomologyTopGO.txt` | Intermediate topGO mapping (Homology) |

And in `test/test_run/results/`:

| File | Description |
|---|---|
| `test_run.run_summary.json` | Run summary with parameters and resource usage |

### Minimum expected DEG counts

| Comparison | Expected DEGs (padj < 0.05) |
|---|---|
| Full model (ALL) | ≥ 150 |
| Stage1 ~ Temperature | ≥ 150 |
| Stage2 ~ Temperature | ≥ 150 |
